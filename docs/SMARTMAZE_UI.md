# SMARTMAZE — UI/UX DESIGN SYSTEM

## 1. Overall Vision

SmartMaze should feel like a premium interactive game rather than a conventional college application.

The visual experience should be:

* Cinematic
* Atmospheric
* Sophisticated
* Minimal
* Interactive
* Mysterious
* Calm
* Premium

The interface should feel carefully designed rather than assembled from generic UI components.

---

## 2. Core Visual Direction

Primary visual concept:

**Cinematic Maze + Modern Architecture + Premium Game Interface**

The experience should feel like entering a mysterious physical environment.

Avoid making SmartMaze look like:

* A generic dashboard
* A cyberpunk game
* A futuristic AI interface
* A neon gaming website
* A conventional CRUD application

---

## 3. Color Direction

Primary palette:

* Deep Forest
* Muted Sage
* Warm Sand
* Soft Ivory
* Stone
* Charcoal

Secondary accent:

* Very subtle antique amber

Colors should generally be muted and sophisticated.

Do NOT use bright neon colors.

Do NOT use excessive glowing effects.

Do NOT make every interactive element brightly colored.

Color should communicate meaning and interaction rather than simply decorate the interface.

---

## 4. Landing Page

The landing page should be cinematic.

Background:

* Slow-motion maze/environment video
* Heavy blur
* Subtle depth-of-field
* Low contrast
* Slight desaturation
* Dark/sage overlay

The video should remain atmospheric and should not overpower the content.

Foreground:

SMARTMAZE

Think. Navigate. Solve.

Short supporting description.

Primary action:

ENTER SMARTMAZE

The entrance interaction should feel like entering the maze rather than clicking a normal website button.

---

## 5. Motion Principles

Animations should be:

* Slow
* Smooth
* Intentional
* Cinematic

Avoid:

* Excessive bouncing
* Fast transitions
* Random movement
* Constant flashing
* Excessive particle effects

Motion should communicate hierarchy and state.

---

## 6. Main Hub

The main hub should not look like a conventional dashboard.

Primary modes:

PLAY MAZE
CREATE MAZE
ALGORITHM LAB
SETTINGS

The interface should use open space, typography and selective surfaces instead of putting everything inside separate cards.

Hovering a mode may subtly change the background/environment.

---

## 7. Gameplay

The maze should be the visual focus.

The UI should stay out of the player's way.

Important information:

* Level
* Timer
* Moves
* Maze state
* Controls

The player should have a distinctive visual representation.

The goal should have a subtle animation.

---

## 8. Maze Visual Language

Maze cells should not feel like generic square boxes.

Possible states:

* Unvisited
* Wall
* Player
* Goal
* Visited
* Exploring
* Final path

Transitions between states should be animated.

---

## 9. BFS Visualization

BFS should feel like an analysis mode.

When BFS begins:

* Normal interface becomes quieter
* Exploration expands from the starting cell
* Visited cells animate
* Queue information may be displayed
* Final path is highlighted
* Statistics can be revealed

The visualization should communicate the algorithm clearly without becoming visually noisy.

---

## 10. Typography

Typography should have strong hierarchy.

Use:

* Large expressive headings
* Clean readable body text
* Small uppercase labels for metadata
* Generous spacing

Avoid excessive font weights and excessive text.

---

## 11. Components

Reusable components should eventually include:

* PrimaryButton
* GhostButton
* Navigation
* GlassPanel
* MazeCell
* MazeGrid
* Player
* Goal
* StatusDisplay
* Modal
* Transition
* PageContainer

Components should be reusable and visually consistent.

---

## 12. Interaction Philosophy

Every interaction should provide feedback.

Examples:

Button:

hover → subtle movement

click → tactile compression

navigation:

hover → environmental response

maze:

movement → animated response

completion:

goal reached → cinematic feedback

---

## 13. Desktop First

SmartMaze is primarily a desktop application/game.

Design for:

* Desktop
* Laptop

Responsive behavior should still be considered.

---

## 14. Important Constraint

SmartMaze must remain generic and extensible.

Do not permanently associate the application with:

* Police
* Cars
* Crime
* Cyberpunk

Those may be future themes or missions, but they are not the identity of the core SmartMaze engine.

---

## 15. Design Rule

The most important rule:

**The maze is the hero.**

The interface should enhance the maze experience rather than compete with it.
